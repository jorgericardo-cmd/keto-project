# Keto Económico & Familiar 🥑🍳

¡Bienvenido al repositorio de **Keto Económico & Familiar**! Este proyecto es un blog y repositorio web interactivo diseñado para demostrar que llevar una alimentación cetogénica (keto) no tiene por qué ser costosa ni complicada. Está optimizado con ingredientes accesibles, de temporada y rendidores, ideal para cuidar la salud y el bolsillo de toda la familia.

---

## 🌟 Características de la Web
- **Plan Semanal Interactivo:** Menús completos para los 7 días de la semana (desayuno, comida y cena) calculados para 4 porciones.
- **Recetario Desplegable:** Cada platillo incluye un botón *"Ver Receta"* que abre una ventana emergente detallando los ingredientes exactos y la preparación paso a paso.
- **Lista de Compras Optimizada:** Clasificada por categorías (proteínas, lácteos y grasas, verduras, despensa) con cantidades estimadas y consejos de ahorro.
- **Guía Rápida Keto:** Conceptos básicos del estilo de vida cetogénico y pilares del ahorro en la cocina.
- **Diseño Responsive:** Adaptado para consultarse cómodamente desde el teléfono móvil, tablet o computadora.

## 🚀 Cómo Publicar y Compartir este Blog Gratis

Puedes publicar esta página web en cuestión de minutos de forma totalmente gratuita para compartir el enlace con tus familiares y conocidos mediante **GitHub Pages**:

1. **Crea un repositorio** en tu cuenta de GitHub con un nombre descriptivo (por ejemplo, `keto-familiar`).
2. Sube el archivo **`index.html`** generado en este proyecto a la raíz de tu repositorio.
3. Dirígete a la pestaña **Settings** (Configuración) de tu repositorio en GitHub.
4. En el menú lateral izquierdo, haz clic en **Pages**.
5. En la sección **Branch**, selecciona la rama `main` (o `master`) y deja la carpeta en `/ (root)`, luego haz clic en **Save**.
6. En un par de minutos, GitHub te proporcionará una URL pública (por ejemplo: `https://tu-usuario.github.io/keto-familiar/`). ¡Ese es el enlace que podrás compartir por WhatsApp!

Alternativamente, puedes arrastrar el archivo `index.html` directamente a plataformas gratuitas como [Netlify Drop](https://drop.netlify.com/) para obtener un enlace instantáneo.
